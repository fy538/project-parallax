# Route Animation Template

**Status:** Planned (Week 5-6)

Draws animated lines between countries showing trade routes, supply chains,
military movements. Line draws progressively using stroke-dasharray animation.
Camera follows the route.

**Data input:** Array of waypoints with [lon, lat] coordinates and labels.

**Dependencies:** react-simple-maps, Mapbox GL (optional for 3D camera).

**Visual reference:** CaspianReport trade route sequences.
