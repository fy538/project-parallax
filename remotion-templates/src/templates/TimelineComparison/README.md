# Timeline Comparison Template

**Status:** Planned (Week 3-4)

Side-by-side historical vs. modern events. Left column shows historical events,
right column shows modern parallels. Events fade in sequentially, synced to
narration beats.

**Data input:** Two arrays of events (historical + modern), each with year,
title, description, and duration.

**Visual reference:** Wendover Productions timeline sequences.

**silicon-trap use case:** 1941 oil embargo timeline vs. 2022 chip controls timeline.
