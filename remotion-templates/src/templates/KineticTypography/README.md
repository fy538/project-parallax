# Kinetic Typography Template

**Status:** Planned (Week 3-4)

Key quotes and definitions appearing on screen with animation. Supports:
- Word-by-word reveal (for English quotes)
- Character reveal (for Chinese: 卡脖子, 举国体制)
- Pinyin + translation layout
- Attribution line (speaker, date, source)

**Data input:** Quote text, attribution, optional Chinese/pinyin pair.

**silicon-trap use case:** Morris Chang: "Globalization is almost dead."
