# Asset Brief Generator

You are generating the two production prompt documents that allow a human operator to
create AI-GEN stills (ChatGPT) and morph clips (Kling / Hailuo) for a Parallax episode.
These documents replace manual prompt authoring — every future episode runs this skill
instead of writing prompts by hand.

## What you produce

1. **`episodes/{slug}/prompts/chatgpt-prompts.md`** — All still prompts: the episode style block
   (paste once per ChatGPT conversation with 4 ref images) + one numbered block per
   still that needs generation (status: "NEW" in shot-list.json).

2. **`episodes/{slug}/prompts/morph-prompts.md`** — All morph clip prompts: global Kling/Hailuo
   settings (paste once per tool session) + one block per morph pair in `morph_pairs[]`.

## Before you start

Read all of these:

1. **`episodes/{slug}/shot-list.json`** — source of truth for assets and morph pairs
2. **`project/ASSET_GENERATION_REGISTER.md`** — doctrine for all three tools (ChatGPT,
   Kling, Hailuo): style rules, prompt structure, quality gates, failure modes
3. **`episodes/{slug}/visual-thread-design.md`** (if it exists) — narrative thread logic,
   why each morph pair was chosen editorially
4. **The episode script** (at `episodes/{slug}/script.md` or similar) — skim beat
   headings to extract the narration context for each shot. You need 1–2 sentence
   fragments from the script that play over each still.

If `prompts/chatgpt-prompts.md` already exists, read it — you are extending or refreshing it,
not starting from scratch. Preserve any prompts that are already written.

## Step 1 — Enumerate shots and morphs

From `shot-list.json`:

- **Stills to generate:** all entries in `assets[]` where `status: "NEW"`. Note the
  `anchor_frame` (null = standalone, an aigen-ID = bridge still), `camera_move`
  (spatial shift from anchor), `beat`, `thread`, `description`, `treatment`.
- **Morphs to generate:** all entries in `morph_pairs[]`. Note `from`, `to`, `tool`
  (kling/hailuo), `duration_sec`, `intent`.

Build a working list before writing anything. Count NEW stills and morph pairs.
Report: "Found N stills to generate and M morph pairs."

## Step 2 — Write chatgpt-prompts.md

### File structure

```
# {Slug} — ChatGPT Image Prompts

> Generated by asset-brief skill, {date}.
> Paste the OPENING MESSAGE once at the start of a new ChatGPT conversation with
> the 4 episode reference images attached (assets/ep-refs/ep-ref-{1-4}-*.png).
> Then paste each shot prompt in order, one at a time.

---

## Opening message (paste once with 4 ref images attached)

[FULL STYLE BLOCK — see ASSET_GENERATION_REGISTER.md § "Episode style block"]

---

## Phase A — Bridge stills (12 new stills)

_One prompt per shot. Paste in order, one at a time. Wait for image before continuing._

### Shot 1 — {id} ({beat}, {thread})
> Narration: "{1–2 sentence excerpt from script that plays over this shot}"
> Anchor: {anchor_frame id, or "standalone"}
> Camera move: {camera_move from shot-list, or "none — establishing"}

[PROMPT TEXT]

...
```

### How to write each still prompt

**Style lock — every shot, no exceptions (ASSET_GENERATION_REGISTER.md sophistication rule 7):**
Each prompt must (a) restate the **flat constructivist register**, (b) **explicitly forbid
realism in the rendering** ("not photorealistic, not a naturalistic / painterly oil painting,
no rendered faces, no volumetric light"), and (c) tell the operator to **lock to a
constructivist reference image** (the Tier-1 refs, or a known-good still like `aigen-01`).

**People — read `project/PICTURE_RULES.md` first.** Two rules go into every opening message
that includes a person. Heads have **no facial parts from any angle**: no eyes, eyebrows or
eye sockets; no nose, nostrils or nose ridge; no mouth or lips; no lines inside the ear; a
profile has no nose or lip bump; shadows and reflections follow the same rule. Bodies are
**anatomically coherent** under the flat rendering: shoulders, elbows, wrists and hands
connect, and each hand can be traced to its own arm. **Never write "no realistic anatomy".**
That phrase was in earlier style blocks and contradicts the second rule.
**Never name a realist painter or tradition** (Benton, WPA mural, Hudson River, academic
realism, "painterly oil") to get warmth or mood — that drifts ChatGPT straight to photoreal.
Warm threads (e.g. the cooperation arc) get warmth from **palette and light**, not a different
art tradition. (The `aigen-11` stag-hunt regen was the canonical drift, May 24 2026.)

**Standalone still** (anchor_frame: null):
- 3–5 sentences: setting, figure count and pose, light source, color balance, mood
- Apply Pika-friendly principles from ASSET_GENERATION_REGISTER.md (dark silhouettes,
  no crowds, minimal text, clear depth layers)
- End with: "No text overlay. 16:9 wide landscape."

**Bridge still** (anchor_frame is an existing aigen-ID):
- Open with: `[Upload: {anchor_frame}-{name}.png as the anchor frame.]`
- Next sentence: `The camera has {camera_move} — describe the spatial shift.`
- Then: describe only what's NEW in this frame (new scale, new detail, new element
  entering frame). Don't re-describe what the anchor already shows.
- Match the treatment field (`standard` vs `conflict`).
- End with: "No text overlay. Same constructivist register as anchor."

**Reasoning you must do:** for bridge stills, read the `description` field AND the
`camera_move` field together and ask: "If I were holding a camera on this anchor frame
and then performed this move, what would I now see?" That's what you describe. The
`intent` in the morph pair that follows confirms the editorial logic.

### Grouping

Group shots by Phase (Phase A = bridge stills, Phase B = standalone atmospherics, etc.)
matching how `prompts/chatgpt-prompts.md` organizes them. Tell the operator how many shots are
in each phase and roughly how many ChatGPT prompt windows they'll need (50-prompt rolling
window per 3-hour session).

## Step 3 — Write morph-prompts.md

### File structure

```
# {Slug} — Morph Clip Prompts (Kling + Hailuo)

> Generated by asset-brief skill, {date}.
> Two sections: Kling pairs (camera/figure-driven) and Hailuo pairs (geometry-driven).
> For each section: paste the SESSION SETTINGS once, then paste each pair block.
> Upload start + end frames as images when prompted by the tool.

---

## Kling pairs ({N} pairs)

### Session settings (paste once)

Tool: Kling 3.0 Standard or Pro
Mode: Image-to-video — start frame + end frame
Resolution: 1080p
Motion intensity: LOW

---

### Pair 1 — {from} → {to}  [{duration_sec}s · {risk_level}]

**Start frame:** {from filename}
**End frame:**   {to filename}
**Duration:**    {duration_sec}s

```
{PROMPT TEXT — 2–3 sentences, camera-move language only, describe only the change}
```

Negative prompt:
```
-neg flicker, morphing, warping, text drift, watermark, jitter{, shot-specific additions}
```

> What to watch: {1–2 sentences on the most likely failure mode for this specific pair}

---

## Hailuo pairs ({N} pairs)

[same structure]
```

### How to write each morph prompt

**For Kling pairs:**
- Describe ONLY the motion or spatial change — never name elements that should stay static
- Camera-move language: "Camera pushes in toward...", "The foreground tightens as...",
  "Background holds while..."
- The `intent` field in shot-list.json is the seed — expand it to 2–3 full sentences
- Add shot-specific negative prompts based on what's in both frames (use the
  ASSET_GENERATION_REGISTER.md § "Shot-specific negative prompt additions" table)

**For Hailuo pairs:**
- Describe the MATERIAL TRANSFORMATION — what does the geometry do?
- "The grid resolves into table edges at the vanishing point..."
- "The stone walls dissolve and the space opens to ocean horizon..."
- Camera holds static unless the intent says otherwise

**Duration assignment** — follow the register:
- 6s: subtle push / dolly / tilt — same scene, small spatial shift
- 8s: figure emergence, architectural transformation, scene-type change
- 10s: HERO morph only (mark one per episode maximum)

**Risk level** — assign each pair:
- LOW: geometry-only change, no figures, palette is stable across frames
- MEDIUM: figure introduction, or large spatial shift
- HIGH: simultaneous figure introduction + space transformation

Include risk level in the pair header. HIGH-risk pairs get a "What to watch" note and
a fallback suggestion (generate intermediate frame, or fall back to hard cut).

### HERO morph

The `intent` field in shot-list.json may contain "(HERO morph)" — or you can identify
it as the single most pivotal visual transition editorially. Mark it clearly in the
file: `### Pair N — from → to  [10s · HIGH · ★ HERO MORPH]`. Write an extended
"What to watch" section for the HERO morph covering 3–4 failure modes to check.

## Step 4 — Write the files

Write both files to the episode directory:
- `episodes/{slug}/prompts/chatgpt-prompts.md` (or append to existing if it exists)
- `episodes/{slug}/prompts/morph-prompts.md` (create; this file rarely exists yet)

Then report:
- How many stills were in prompts/chatgpt-prompts.md (existing + new)
- How many morph pairs in prompts/morph-prompts.md, split by tool
- The one unblocked morph pair (if any) that can be generated immediately because
  both start + end frames already exist in `public/episodes/{slug}/`
- The single highest-value next action

## What you do NOT do

- Do not write Pika prompts — those are in `pika-prompts.md` or `video-prompts.md`
  and are per-still, not per-morph-pair. They are not part of this skill's output.
- Do not modify shot-list.json or asset-registry.json
- Do not evaluate whether the stills are editorially correct — trust visual-spec
- Do not generate images yourself — you are writing prompts for a human to paste

## Format requirements

- Prompts must be in fenced code blocks so the operator can triple-click to select
- Each pair/shot header must include the IDs and duration so the operator can scan
- Add a brief "Session plan" at the top of each file: how many ChatGPT windows
  needed (at 50 prompts per window), how many Kling sessions, how many Hailuo sessions
- The morph-prompts.md HERO morph gets a star marker ★ in its header
