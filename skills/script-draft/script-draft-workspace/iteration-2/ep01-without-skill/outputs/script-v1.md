## PRODUCTION NOTES

**Pacing observations:**
- Beat 1 (2:30) establishes the paradox with surprising speed — good tension opener.
- Beat 2 (4:30) is the longest, carrying two historical parallels. The split-screen timeline should help viewers track two narratives simultaneously. The emotional landing ("genuine uncertainty") is critical.
- Beat 3 (5:00) is narrative-heavy with multiple companies and concepts. MG should be leaned on heavily here to break up exposition. The chess vs. go visualization is a P1 moment and should anchor the beat visually.
- Beat 4 (4:00) uses Bayesian framing but doesn't name it. The three "what we thought" cards should have consistent visual treatment to make the structure obvious. This is the most data-dense beat.
- Beat 5 (2:00) is the closing "so what" — return to the cliff metaphor and personal stakes. Should feel contemplative, not alarmist.

**Visual motif execution:**
The supply chain web (mentioned in angle memo) appears in three moments:
1. Beat 1: Clean, efficient network (the marvel of globalization)
2. Beat 3: Tangled and strained (as both sides pull)
3. Beat 5: Splitting into two diverging networks (bifurcation)

This can be implemented via the RouteAnimation template with a `progress` parameter showing network tension increasing across the episode.

**Visual-first moments** (where image precedes narration):
- Beat 2, COCOM parallel: The ChoroplethMap showing COCOM member states should appear 2-3 seconds before "seventeen Western nations" is spoken. Viewers see the map first, then narration explains it.
- Beat 3, chess vs. go: The ChessVsGoVisualization should appear before "The US plays chess" is said. The metaphor lands harder if viewers see it before hearing it named.
- Beat 4, prior belief cards: Each belief card should precede the "what happened" data by 1-2 seconds, creating visual rhythm.

**Counterpoint moments** (visual contradicts narration for emphasis):
- Beat 3: While narration says "the controls are working," the SMIC yield curve should be climbing simultaneously. The visual shows the constraint isn't total.

**Radio edit test:** Strip all visual specs and read the narration aloud. It should work as pure podcast audio — tension, pacing, emotional rhythm intact. All structural arguments should be comprehensible from narration alone; visuals amplify, not replace.
