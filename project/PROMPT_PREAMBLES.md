# Parallax — Prompt Preambles

> Created: May 4, 2026
> Owner: tools/recraft/recraft.py (`REGISTER_PREAMBLES` dict)
> Related: VISUAL_LANGUAGE.md (registers), AI_VIDEO_PIPELINE.md (grounding spec), palette.json (colors), tools/brand-treatment/ (LUT pass)

## What this document is

The design rationale and full text of the prompt preambles that get prepended to every Recraft API call. This is the *prompt-level* half of Parallax's two-stage brand unification architecture.

## Why this exists

The brand-treatment LUT pipeline (`treat.py`, `treat_video.py`) was originally the only mechanism for unifying source imagery to brand. That works but has limits: when the source image is far off-brand (cool corporate blue lobby, fluorescent cleanroom), the LUT has to do heavy color rescue, which produces obvious cross-talk, muddy shadows, and clipped highlights — the "obvious LUT" feel.

The fix is to do brand work earlier in the pipeline. If the source image already lands in the warm-umber-amber zip code, the LUT does the final 10% polish instead of 60% rescue. Result: more naturalistic outputs, more cohesion across registers.

This is how cinematographers think about it. You light *for* the grade, not against it. Roger Deakins' Sicario lighting palette is already 80% of the final film look; the colorist nudges, doesn't transform.

## Architecture: two stages

```
   Description (from script right column)
              │
              ▼
   ┌──────────────────────────────────┐
   │  STAGE 1: Prompt-level (here)    │
   │                                  │
   │  REGISTER_PREAMBLES[register]    │
   │    + description                 │
   │    + context                     │
   │    + negative prompts            │
   └──────────────────────────────────┘
              │
              ▼
       Recraft V3 API
              │
              ▼  (raw on-brand-ish output)
   ┌──────────────────────────────────┐
   │  STAGE 2: Treatment-level        │
   │                                  │
   │  treat.py (raster) /             │
   │  treat_video.py (video) /        │
   │  apply_duotone_svg (vector)      │
   │    Duotone LUT                   │
   │    Grain overlay                 │
   │    Vignette                      │
   └──────────────────────────────────┘
              │
              ▼
   Brand-locked asset → Remotion / NLE
```

Either stage alone is weaker than both together.

## The three registers

Per VISUAL_LANGUAGE.md, every visual surface in a Parallax video belongs to one register. Recraft generates two of them; the third (analytical) normally lives in Remotion.

| Register | Function | Recraft Style | Generated by |
|---|---|---|---|
| **Atmospheric** | The *feeling* of the system — civilizational mood, dread, ambition | `vector_illustration` | Recraft (constructivist) |
| **Grounding** | The *presence* of humans in the system — depersonalized via mannequin faces | `realistic_image` | Recraft (photoreal) |
| **Analytical** | The *understanding* — data, structure, comparison | code-locked Remotion | rare Recraft fallback |

## Cross-register cohesion vocabulary

Both atmospheric and grounding preambles share these phrases. The viewer's eye picks up shared composition + mood + palette across radically different source styles, and the result reads as one channel.

- "warm umber-amber palette" / "warm-umber spectrum"
- "editorial weight"
- "civilizational scale"
- "documentary" / "intellectually rigorous"
- "heavy chiaroscuro" / "deep shadows giving way to warm highlights"
- Explicit palette hex codes from `palette.json` (ink, walnut, umber, gold, rust, bone, paper)

## Atmospheric preamble (Register 2 — constructivist)

```
Editorial illustration in the Parallax constructivist style. Soviet
constructivism meets art deco propaganda poster, with flowing organic
forms (smoke, ribbons, cables) woven through brutal industrial geometry
(factories, towers, pipes, machinery). Restricted warm palette: deep ink
(#1C1814), walnut (#5C4A3D), umber (#8B7355), burnt amber / gold
(#C4A747), rust (#A64D46), and bone (#F0E6D0) on paper (#F5F0E8)
background. No other colors. Bold compositional confidence,
monumentalist scale, low horizon line, heavy contrast, color-blocked
forms with no soft shading or gradients. Mood: civilizational stakes,
industrial ambition, technological dread, editorial weight,
intellectually rigorous.
```

**Negative prompts:**

```
Avoid: corporate clip art, children's book illustration, pastel tones,
cool blue or teal, photorealistic rendering, 3D render look,
gradient-heavy fills, cute or whimsical mood, flat tech-startup
aesthetic, Memphis design, isometric perspective. No text, no labels,
no watermarks, no human faces.
```

**Why these choices:**
- Explicit palette restriction with hex codes — Recraft V3 follows palette instructions literally; without this it drifts to default illustration palette (often brighter, more saturated, more colors).
- "No soft shading or gradients" — the constructivist aesthetic is graphic and color-blocked. Without this constraint Recraft adds painterly shading that breaks the propaganda-poster feel.
- "No human faces" — keeps figures abstracted; faceless figures in atmospheric register appear as silhouettes, not portraits.
- Negative prompts target the most common failure modes: Memphis design (trendy 80s revival), flat tech-startup illustration (vector clip art), and Adobe-stock cleanliness.

## Grounding preamble (Register 3 — photoreal mannequin)

```
Editorial documentary photography for a geopolitics video essay.
Photorealistic environment rendered with accurate materials, lighting,
and reflections. Human figures present but with completely smooth
featureless mannequin faces — no eyes, no nose, no mouth, just smooth
convex skin where features would be — while clothing, body, and hair
remain fully realistic and context-appropriate. Warm tungsten or
natural lighting, heavy chiaroscuro: deep umber shadows giving way to
amber midtones and bone highlights. Slightly desaturated color grade
in the warm-umber spectrum, ready for further color treatment. Shot on
35mm film, shallow depth of field, editorial composition. Mood:
documentary reconstruction, contemplative weight, civilizational
scale. The figures are depersonalized to represent roles rather than
individuals.
```

**Negative prompts:**

```
Avoid: cool corporate blue, clinical fluorescent white balance, Adobe
stock photo aesthetic, teal-and-orange Hollywood grade, high-key
advertising lighting, shiny CGI render look, cartoon style,
illustration look. Mannequin faces must be smooth and convex — never
concave or scooped inward. Faces must be completely featureless with
no facial features whatsoever. No identifiable real individuals.
```

**Why these choices:**
- "Convex" + "never concave or scooped inward" — directly addresses GPT Image 2's known failure mode (concave/scooped faces, per AI_VIDEO_PIPELINE.md). Flux 2 Pro handles convex literally; Recraft is somewhere in between.
- "Slightly desaturated… ready for further color treatment" — explicitly tells Recraft not to pre-grade. Stage 2's LUT can't push amber if the source is already saturated cyan.
- "Warm tungsten or natural lighting" lets temperature *within* the palette vary by scene — a command center can still feel cold (deep shadows, hard edges) without being cyan-fluorescent. Unify palette, vary temperature through lighting design.
- Negative prompts target Recraft's stock-photo bias: it defaults to Adobe-stock aesthetic when not redirected, which is the single biggest source of off-brand drift.

## Analytical preamble (Register 1 — fallback only)

```
Technical diagrammatic illustration for an analytical video essay.
Geometric vector forms, clean precise lines, balanced negative space,
labeled-style nodes without actual text. Restricted palette: ink
(#1C1814) lines on paper (#F5F0E8) background, with burnt amber / gold
(#C4A747) and rust (#A64D46) accents only where data weight demands
attention. No other colors. Mood: information-first, analytical,
code-clean. Composition reads left-to-right or top-to-bottom for
diagrammatic clarity.
```

**Reserved for:** rare cases where a diagrammatic illustration genuinely belongs in Recraft rather than Remotion (e.g., when the diagram needs hand-drawn organic feel, or as quick prototyping before code). Default for all true analytical content remains Remotion templates.

## How the temperature-not-color rule plays out

A common worry: if every photo is "warm tungsten," won't the cold tension of a command center disappear? No — and this is the important nuance.

The preamble unifies *palette* (umber/amber/rust/bone), not *lighting temperature*. A scene can feel cold within that palette through:

- **Lighting direction.** Hard sidelighting or top-down fluorescent (still warm-grade) reads cold.
- **Shadow density.** Deep umber shadows + small warm highlights reads tense; broad amber midtones reads contemplative.
- **Composition.** Hard geometry, low ceilings, locked-off cameras read cold; soft curves, high ceilings, drift cameras read warm.
- **Color ratio.** A predominantly bone-highlights scene (bright, sterile) vs. predominantly umber-shadow scene (oppressive, hidden).

The grounding preamble explicitly leaves these knobs free for the description to set. "Dim command center with operators at glowing screens, hard side-light from monitors, deep ink-black corners" produces a cold-feeling scene that still grades into the brand palette cleanly.

## Recommended A/B test

To validate the prompt-level pass actually does work, run a four-way comparison on the same prompt:

1. **Raw** — `recraft.py generate "scene description" --raw -o test_1_raw.png`
2. **Mode-only** (legacy) — `recraft.py generate "scene description" --mode illustration -o test_2_mode.svg`
3. **Register-only** — `recraft.py generate "scene description" --register grounding -o test_3_register.png`
4. **Register + treat** — `recraft.py generate "scene description" --register grounding -o test_4.png`, then `treat.py test_4.png --ramp standard -o test_4_treated.png`

Lay 1, 3, 4 side-by-side against an existing constructivist illustration. Cohesion should be ordered: 4 > 3 > 1.

If 4 ≈ 3 (treatment adds nothing), the preamble is doing too much and the LUT has nothing to refine — possibly over-constrained. Loosen the preamble.

If 3 ≈ 1 (preamble adds nothing), Recraft isn't following the preamble — possibly too long, possibly too abstract. Tighten the preamble.

If 4 >> 3 >> 1, the architecture is working as designed.

## Maintenance

When updating preambles:

1. Edit `REGISTER_PREAMBLES` in `tools/recraft/recraft.py`.
2. Regenerate any reference images that were generated under the old preambles.
3. Update this doc's "full preamble text" sections to match.
4. Note the change in DECISIONS.md if it's a meaningful aesthetic shift.

When updating the brand palette in `palette.json`:

1. The hex codes embedded in the preambles here must be updated by hand. They are *deliberately* duplicated rather than imported, because Recraft sees the literal characters of the prompt and benefits from hex codes appearing inline. A future refactor could template these from `palette.json` at runtime, but it's not worth the indirection until palette changes happen frequently.

## Open questions

1. **Per-shot negative prompt overrides.** Some shots may need to relax a negative (e.g., an atmospheric piece that *should* have a single isometric element). Current API only accepts the register's full negative block. Consider adding `negative_override` field to shot-list.json.
2. **Style reference images vs. preambles.** Recraft V3 supports style reference images. Once the EP01 reference library is built (per AI_VIDEO_PIPELINE.md Step 1), test whether reference images replace or complement the textual preamble.
3. **Conflict register flavor.** Currently the LUT has three flavors (standard / conflict / editorial) but the preambles don't tonally distinguish. Should there be a `--mood {standard,conflict,editorial}` modifier that nudges the preamble's mood vocabulary toward tension or archival?
